# 📊 GCP Data Pipeline & Saudi Tech Jobs Analysis

An end-to-end data engineering and analytics project built using **Google Cloud Platform (GCP)** to analyze salary trends and job distributions in the Saudi technology market.

## 🛠️ Tech Stack & Architecture
* **Data Storage:** Google Cloud Storage (GCS)
* **Data Warehouse & Query Engine:** BigQuery
* **Data Visualization:** Looker Studio
* **Language:** SQL

## 🎯 Project Workflow
1. **Data Ingestion:** Uploaded raw tech market dataset (`saudi_tech_jobs.csv`) into BigQuery.
2. **Data Processing:** Wrote analytical SQL queries to clean, aggregate, and calculate key metrics such as average salaries by job title, experience level, and location.
3. **Data Visualization:** Built a live, interactive dashboard in **Looker Studio** with cross-filtering capability.

## 📈 Key Insights & Results
* Aggregated salary metrics across major tech roles (Data Engineers, QA Specialists, Cloud Architects).
* Analyzed salary distributions by region (Riyadh, Jeddah, Khobar).
* Created real-time metrics for entry, mid, and senior level roles.
